# BrightFuture Academy Website

A modern, animated school website with sections for:

- Hero banner and school overview
- Notices board
- Test and exam results
- Homework and assignment tracking
- Class schedule
- School gallery
- Contact/admission form
- Responsive mobile-friendly layout

## Files

- `index.html` – main website structure
- `styles.css` – responsive styling and animations
- `script.js` – mobile menu and reveal animations

## Run locally

Open `index.html` directly in a browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

You can replace the school name, colors, and text with your own details to match your institution.
